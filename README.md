# ☕ Coffee Sales Analysis – Power BI Dashboard

## 📊 Project Overview

The **Coffee Sales Analysis** project is an interactive Power BI dashboard designed to analyze coffee shop sales data and generate meaningful business insights.

This project focuses on sales performance, product performance, store-wise analysis, customer ordering patterns, and time-based sales trends.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze overall coffee shop sales performance
- Identify top-performing products
- Compare sales across different store locations
- Analyze product categories and product types
- Identify peak sales days and hours
- Analyze monthly sales trends
- Compare current and previous month performance
- Create an interactive business intelligence dashboard
